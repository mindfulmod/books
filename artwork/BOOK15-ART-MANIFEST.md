# Book 15 art manifest

Three journey plates for *The Etiquette of Companionship*. The app references these paths already; dropping the files in makes them appear with no code change.

## Specs

| | |
|---|---|
| Serving directory | `public/assets/system/` |
| Master directory | `artwork/system-source/` (full-resolution PNG) |
| Full size | 1600 × 900 JPEG (16:9) |
| Thumbnail | 480 × 270 JPEG |
| Thumbnail path | derived automatically by replacing `.jpg` with `-thumb.jpg` — both files are required |
| Crop safety | the extreme top and bottom are cropped on narrow viewports; keep the load-bearing content out of those bands |

## Files

Alt text is already written into `src/book15.ts` and is what each plate has to depict. It is reproduced here as the brief. This book has three journeys.

**Set note.** No people, despite the subject — every plate is a pair of objects or a place set for two. The book's argument is that friendship has determinate content that can be listed and failed, so these should read as evidence of a relationship rather than as a picture of one.

### 1. `book15-two-hands.jpg` + `book15-two-hands-thumb.jpg`
- **Journey** 01 — Is a friendship something you can fail?
- **Accent colour** `#278d91`
- **Must depict** Two identical work gloves laid side by side on a bench, both worn in the same places.
- **Argument it carries** Two brothers are likened to two hands and not to a hand and a foot, because the hands work toward a single purpose. The gloves must be a genuine *pair* — same size, same make — and the wear must match on both, which is what shows they did the same work. Not one glove worn and one new.

### 2. `book15-my-shoe.jpg` + `book15-my-shoe-thumb.jpg`
- **Journey** 02 — How far does this actually go?
- **Accent colour** `#bf7a35`
- **Must depict** A single pair of worn sandals set at a doorway among several other pairs, indistinguishable from them.
- **Argument it carries** At the highest rank, none of them distinguished his own baggage from another's — and one of them would not keep company with anyone who said *my shoe*. The pairs must be genuinely hard to tell apart: same style, similar wear, no pair set aside or turned differently. If a viewer can pick one out, the plate has failed.

### 3. `book15-empty-chair.jpg` + `book15-empty-chair-thumb.jpg`
- **Journey** 03 — What do I owe when nothing is happening?
- **Accent colour** `#c25f50`
- **Must depict** Two chairs at a table with one occupied place setting and one empty, the empty place still laid.
- **Argument it carries** What is said about a friend when he is absent — silence about his faults, speech about what is good in him — plus the rights that continue after death. *Still laid* is the whole plate: the absent place has been kept, not cleared. Warm and unmelancholy; this is a place held, not a loss.
